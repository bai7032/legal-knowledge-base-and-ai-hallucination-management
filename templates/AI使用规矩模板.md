# AI 使用规矩（防幻觉）

> 前半部分是**可直接复制粘贴的提示词**，后半部分是道理。
> 把提示词放进你的 skill、工作说明书，或每次开新对话时贴给 AI。
> 优先级从高到低，不要调换顺序。

---

## 可直接复制的提示词

> 改编时**三要素不得删除**：【法条原文】+【路径（精确到条号）】+【读取回执】。
> 可以按场景增补字段，但不能删——删了这条提示词就失效了。

### 通用版：贴在每次对话开头，或写进 skill / 工作说明书

```
你是我的知识库助手。知识库根目录：【填写路径】。

引用规则（优先级最高，不可绕过）：

0. 引用法条只能取自 01_法律规范/_现行有效/ 下的文件。
   _已废止/ 里的文件仅供新旧对照，禁止作为引用依据。
   引用前先确认文件是现行有效版本，不是历史版本。

1. 禁止凭记忆引用任何法律、法条、司法解释。给出法条前必须先读取知识库原件，
   逐字摘录，不得改写、不得省略、不得调整语序。
   如因 OCR 错字或版式原因无法逐字确认，必须标注"需人工核对"，不得自行补全。

2. 任何法律建议必须包含以下五样，缺一样不合格：
   【建议】：具体要做什么
   【法条原文】：《法律全称》（版本，生效日期施行）第 X 条：完整条文
   【路径】：精确到文件+条号（请查验法律原文）
   【读取回执】：已读取的文件、定位到第几条、摘录片段
   【提示】：本内容仅为检索辅助，不构成法律意见，请人工复核

3. 没有【读取回执】就不许给出法条结论。
   指不出文件、定位不到条，就是没读，此时必须明说读不出来，
   不得声称已核对。

4. 把两类内容分开标注，不得混写：
   【法定标准】= 法律明文，可引用，需核对条号与原文
   【实务策略】= 你自己推的或总结的，不能当依据，只能当思路

5. 知识库里找不到、或该问题法律上本身就有争议尚无统一司法解释的，
   必须明说："目前知识库中未找到明确规定，建议查阅【具体来源】"。
   严禁编造条文、条号、文号、案例。
```

### 查法条专用

```
请回答：【你的问题】

要求：
- 先读 01_法律规范/_现行有效/ 下的原件，不要凭记忆，不要读 _已废止/ 的版本。
- 回答末尾用这个格式：
  【法条原文】《法律全称》（版本，生效日期施行）第 X 条：【完整条文】
  【路径】01_法律规范/_现行有效/法律/【文件名】#第X条（请查验法律原文）
  【读取回执】已读取上述文件第 X 条
  【提示】仅为检索辅助，不构成法律意见，请人工复核
- 如果库里查不到，或该问题存在司法解释分歧，直接告诉我查不到，
  不要给一个看起来合理的答案。
- 如果原件是扫描件、OCR 有错字，摘录后标注"需人工核对"。
```

### 写文书专用

```
请基于我的知识库起草【文书名称】。

要求：
- 每一处法律依据都要先读 01_法律规范/_现行有效/ 下的原件。
- 文末单独列一份"法律依据清单"，每条格式：
  《法律全称》（版本，生效日期施行）第 X 条：【完整条文】
  路径：【文件路径】#第X条（请查验法律原文）
  读取回执：已读取该文件第 X 条
- 凡是你自己推出来的论点，单独放在"说理"部分，并注明"以下为分析意见，
  非法律明文"。
- 库里没有依据的地方，不要用相近条文顶替，直接写"此处无明确依据，需进一步检索"。
- 涉及当事人姓名、案号、住址等敏感信息时使用化名或脱敏表述。
```

### 审查文书专用

```
请扮演对面代理人，专门找这份文书的问题。
重点看四处：
1. 诉讼请求或结论之间是否自相矛盾
2. 事实与理由有没有证据闭环（每一项主张能否对应到具体证据）
3. 法律依据的条号是否准确、是否引了已失效版本或旧条号
4. 引用依据时有没有给出读取回执（没有回执的依据视为存疑）

输出格式：每个问题写清楚"问题—风险—修改建议"。
引用法条时照旧附【法条原文】【路径】（精确到条号）【读取回执】【提示】。
查不到依据的地方直接标注"需核实"，不要替我补一个。
```

### 兜底提示：只要一句最短的

```
引用法条时请附【法条原文】和【路径（精确到条号）（请查验法律原文）】及【读取回执】；
只取现行有效版本；查不到就明说查不到，不要编。
```

## 规矩的原理（理解为什么这么写，条文变了不用重学）

## 第 0 条：原件必须可信且现行有效

**这一条排在所有引用规则之前。**

如果你要求 AI"必须读原件"，而库里放的是旧版法条，这条规矩反而成了错的向导——它会非常忠实地把旧条号念给你。

**库内每个法条文件必须标注四项**：版本、生效日期、来源、效力状态。文件名里就带上：

```
01_法律规范/_现行有效/法律/中华人民共和国行政复议法_2023修订_2024-01-01施行_现行有效.pdf
```

**目录要物理隔离**：

```
01_法律规范/_现行有效/   现行版本——引用只准用这里
01_法律规范/_已废止/     历史版本，仅供新旧对照，禁止直接引用
01_法律规范/_新旧对照/   条号映射表
```

**修订频繁的法律必须做新旧条号映射表**：

| 条目 | 旧法（1999） | 新法（2023修订，2024-01-01施行） |
|---|---|---|
| 申请期限 | 第九条 | **第二十条** |
| 审理期限 | 第三十一条 | **第六十二条** |

有了这张表，AI 引用错位几秒内就能被肉眼发现。

## 一、禁止凭记忆引用法律

**要求**：给出法条之前，必须先读取知识库中的原件。

写"禁止"而不是"建议"。原因是幻觉恰好发生在 AI 自己觉得差不多的时候——它当时还说"已为您核实"，它不觉得自己在编。留余地的"建议"形同虚设。

**这一条要落地成可审计的【读取回执】，不能只是一句禁令。**

光说"禁止凭记忆"无法验证——你不知道它到底读没读。所以规定：**没有读取回执，不允许进入法条引用环节。**

```
【读取回执】已读取：01_法律规范/_现行有效/法律/中华人民共和国行政复议法_2023修订_2024-01-01施行_现行有效.pdf
         定位：第 20 条
         摘录：公民、法人或者其他组织认为行政行为侵犯其合法权益的，可以自知道……
```

读不出来就明说读不出来。**指不出文件、定位不到条，就是没读**，此时不得声称已核对。

## 二、给出法条依据时，必须附查验提示和精确路径

**这是防幻觉最关键的一条。**

任何法律建议必须包含以下五样，缺一样不合格：

```
【建议】：具体要做什么
【法条原文】：《法律全称》（版本，生效日期施行）第 X 条：完整条文
【路径】：精确到文件+条号（请查验法律原文）
【读取回执】：已读取上述文件第 X 条；条号与原文核对一致
【提示】：本内容仅为检索辅助，不构成法律意见，请人工复核
```

**路径必须精确到条，不能只写"知识库中的位置"**：

```
【路径】01_法律规范/_现行有效/法律/中华人民共和国行政复议法_2023修订_2024-01-01施行_现行有效.pdf#第20条（请查验法律原文）
```

引用印刷版且页码明确时，用 `#第5页` 代替 `#第20条`——实务里"第 5 页第 2 行"是能直接写进法律意见书的坐标。

**为什么提示和路径必须一起给**：提示语负责让你**停一下**，路径负责让你**停得下来之后有地方可去**。光有路径不催你去看，光有提示不告诉你去哪儿查。

## 三、逐字摘录，而不是"一字不差"

原本写"输出与原件一字不差"，实操中改为：

> **逐字摘录，不得改写、不得省略、不得调整语序。如因 OCR 错字、换行断字或版式原因无法逐字确认，必须在该条后标注"需人工核对"，不得自行补全或猜测。**

AI 很难保证绝对一字不差——PDF 提取会带入换行空格，扫描件 OCR 会认错字。要求"逐字摘录"，它至少不能自己改写；要求"一字不差"，它可能为了达标而伪造一致性。

## 四、把两类内容分开标注

| 类型 | 标注 | 能怎么用 |
|---|---|---|
| 法律明文 | 【法定标准】 | 可以引用，需核对条号和原文 |
| AI 自己推的、总结的 | 【实务策略】 | 只能当思路，不能当依据 |

这两类混在一起看着一样，性质完全不同。分开标注之后，你至少知道哪句话是可以查的，哪句话是没有出处的。

## 五、找不到就说找不到

库里没有资料，或者这个问题法律上本身就有争议、还没有统一司法解释的，必须明说：

> 目前知识库中未找到明确规定，建议查阅【具体来源】。

**不允许编。宁可空着，也不能填一个看起来很像回事的东西。**

这一条在法律场景里比听起来更重要：

- 一个错误的条号**可以改**——你查一下就发现了，而"请查验法律原文"就是在提醒你真的会去查
- 一段凭空生成的话**你根本不知道它从哪来**——它已经用笃定的语气进了你的判断里

所以在法律上，"说不知道"这个能力，比"答得上"更值钱。

## 六、格式上优先 PDF 和 TXT，少用 Word

这不是讲究，是为了守住"必须读原件"这条底线。

- **PDF**：排版、页码、印章位置在任何设备上都固定。实务里"第 5 页第 2 行"是要写进法律意见书的坐标，页码漂了就失去引用价值。
- **TXT**：纯文本，检索零干扰，也能直接转 Markdown。
- **Word**：换版本、换软件打开页码会飘，一个法条被挤到两页去，扫一眼就漏。

两个都留：PDF 当原件用来核对，TXT 当底本用来检索。

**扫描版 PDF 必须先 OCR**，否则里面没有可读取的文本层，"必须读原件"就是一句空话。OCR 后保留页码映射（PDF 第 N 页 = TXT 第 M 行），这样引用路径才能写 `#第N页`。

**原件放在库里，"必须读原件"才不是一句空话。**

## 七、保密与人工复核

法律知识库常含案卷材料、客户信息、商业秘密。这两条不能省：

**给 AI 的内容必须先脱敏。** 当事人姓名、身份证号、住址、手机号、银行账号、案号中的当事人信息、未公开的商业数据，一律替换为化名或占位符。需要 AI 处理时用脱敏副本，需要人工核实时再对照原件。

**AI 的输出不得直接作为对外法律意见。** 它的作用是帮你快速定位条文、搭起草稿框架、做交叉检查。**所有对外文件必须经人工逐条复核后签发。**

## 八、真实案例：幻觉长什么样

**AI 答对了，依据答错了。** 这是最难防的一种，因为答案对，人就不会怀疑依据。

被问"行政复议申请期限多久"，AI 回答"六十日"——这个答案是对的。条号标的是《行政复议法》第十五条。实际该条内容是"同一行政复议案件申请人人数众多，可以由申请人推选代表人"，与期限无关。

审理期限标"第三十一条"，实际是申请材料补正通知。正确定位：申请期限第二十条，审理期限第六十二条。

**为什么会错**：旧版《行政复议法》里审理期限确实在第三十一条。它把旧法的条号搬到了新法上。数字记住了，条号记岔了。

**为什么难发现**：它错得很有章法——条号、书名、完整条文一样不缺，标着【法条原文】【来源/路径】，末尾还写"请查验法律原文"，甚至分了"法定标准/实务策略"两栏。那个"请查验"恰恰是最像真的部分，让人以为它严谨。

**根子**：库里有原件它也不读。它从训练材料里取旧条文安到新法上，甚至知道要找"现行有效"的法，态度端正，只是拿错了。

**而且它可能连库里的原件都是旧的**——这就是第 0 条要解决的情况。

## 九、配套核对工具

`scripts/verify_citation.py` 可以在法条文本中定位「第 X 条」，用于快速确认条号：

```bash
# 查第 20 条写了什么
python verify_citation.py <法条文件路径> --article 20

# 查多条
python verify_citation.py <路径> --article 20 --article 62

# 先看文件里有哪些条
python verify_citation.py <路径> --list

# 按关键词反查条号
python verify_citation.py <路径> --find "六十日"
```

支持 .txt / .md / .docx / .html，只读，不访问网络。

**重要限制**：这个工具只能确认「文件里第 20 条写了什么」，**不能确认「现行法的第 20 条是这一条」**。法条编号会因修订而变动，用之前务必确认文件本身是现行有效版本。

## 十、把规矩写成固定格式

如果你的工具链支持 skill 或工作说明书，直接把上面这些写进去，让 AI 每次照做，而不是每次临场发挥。

规矩只有落到机制里才靠得住。"下次小心一点"这种念头靠不住——下次赶时间、心情不好，警觉就没了。

**免责说明**：以上为资料管理方法与输出格式约定，不构成法律意见。法规以官方公布的现行有效版本为准；AI 输出仅为检索辅助，所有对外文件必须经人工复核后签发。
