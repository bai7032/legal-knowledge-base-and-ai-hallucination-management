# 法律知识库搭建与 AI 防幻觉 (Legal KB Builder & Anti-Hallucination)

> **两个核心痛点**：资料太乱找不到？AI 引用法条总是编造？
> 本技能提供从资料准备、目录设计、批量归类、索引建立，到日常调用与 AI 引用防幻觉的完整工作流。

## 💡 这个技能解决什么问题？

1. **搭建知识库**：将散落的资料结构化为可查询、可信任的法律知识库。
2. **防止 AI 幻觉**：给 AI 立一套「读取回执」规矩，防止“答案对、依据错”的旧法条搬新法问题。

## 📂 目录结构
- `SKILL.md`：技能核心说明与防幻觉五条规矩。
- `scripts/`：纯 Python 标准库实现的辅助工具（无需 `pip install`）。
  - `kb_inventory.py`：扫描目录，生成含效力状态的全量清单。
  - `kb_migrate.py`：按关键词映射批量归类文件。
  - `verify_citation.py`：在法条文本中定位「第X条」，核对条号。
- `templates/`：开箱即用的 Markdown 模板（AI规矩、目录方案、README）。
